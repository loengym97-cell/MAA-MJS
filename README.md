# 基于 MaaFramework 流水线语言与接口协议的游戏自动化研究项目

以 [MaaFramework](https://github.com/MaaXYZ/MaaFramework)（任务流水线协议 Pipeline Protocol + ProjectInterface 接口协议）为研究框架，以名将杀「千里走单骑」模式为实验对象，研究 JSON 流水线语言描述、图像识别（模板匹配 / OCR）、自定义识别与动作（Agent 协议）等游戏自动化技术。

## 使用说明

### 一、环境准备（模拟器）

1. **模拟器**：推荐 mumu 12（雷电也可以，群友反馈效果更好，其他模拟器不保证能跑）。
2. **分辨率**：模拟器分辨率设置为 **1600×900**（软件按 1280×720 等比缩放识别，分辨率不对可能识别不准）。
3. **开启 ADB 调试**（重要，必须自己开）：
   - 打开模拟器「设置」→「开发者选项」→ 开启 **ADB 调试**（部分模拟器叫 USB 调试/远程调试）
   - 如果找不到开发者选项：设置 → 关于手机 → 连续点击版本号 7 次解锁
4. **进入游戏**：打开名将杀，进入千里走单骑主页，**关闭陌生人邀请**。

### 二、安装与启动

1. 下载最新 Release 压缩包并解压（保持目录结构，勿改名）。
2. 首次使用：以管理员身份运行 `DependencySetup_依赖库安装_win.bat`（安装 VC++ / .NET 运行时）。
3. 运行 `MFAAvalonia.exe`，在「连接操作」选择模拟器设备，勾选任务后点开始。

### 三、任务入口怎么选（重要）

| 入口 | 什么时候用 | 说明 |
|---|---|---|
| **千里走单骑入口** | 在千里走单骑主页、**选将入口还没选择武将**的时候用 | 自动点开始挑战 → 自动选将开打 |
| **继续战斗入口** | 已经**点进去选关卡树**（选地图/选关卡界面）的时候用 | 从地图界面继续推进 |

> 💡 **选将说明**：任务默认选择武将 **吕布**（速度快），**吕布必须出现在千里选将界面的第一页**，否则选不到会卡住。需要换武将的话，在任务设置里把「选将」改成你想要的（也要在第一页）。

### 四、卡住了怎么办

双击软件目录下的 `收集排障信息.bat`，把生成的 `排障信息_日期.zip` 发给开发者或 AI（附一句"卡在 XX 界面"），最快 5 分钟定位问题。


## DeepSeek Harness（DSH）使用教程

本项目的问题排查与适配工作均由 **DeepSeek Harness（DSH）** 协助完成——它是一套 DeepSeek 官方出品的 AI Agent 工具链，可以让 AI 直接读文件、跑代码、查资料、改代码、提交 git，像真人程序员一样干活。

**GitHub 仓库：** [deepseek-ai/deepseek-harness](https://github.com/deepseek-ai/deepseek-harness)

### 快速开始

1. **安装 Node.js**（18+）：https://nodejs.org
2. **安装 DSH**：
   ```bash
   npm install -g @deepseek-ai/dsh
   ```
3. **启动**：
   ```bash
   dsh
   ```
   首次启动会打开浏览器界面（或提示配置），按引导填入 API Key / 选择模型即可使用。

### 用它排查本软件的问题

1. 双击软件目录下 `收集排障信息.bat`，生成 `排障信息_日期.zip`
2. 把 zip 解压后的文件目录交给 DSH，说一句：**"分析这些日志和截图，我的挂机脚本卡在 XX 界面，帮我找原因"**
3. DSH 会自己读日志、看截图、对照代码，直接给出结论和改法（甚至直接帮你改好）

### 日常用法举例

- "帮我看看 `maafw.log` 里今天的报错"
- "把 `resource/pipeline/继续挑战.json` 的事件选项再加几个词"
- "这个 OCR 识别不到按钮，帮我截个图定位 ROI 在哪"
- "分析这些失败截图，哪些是配置问题哪些是时机问题"

> 遇到任何问题，优先用 DSH + 排障 zip，比群里干等快得多。
